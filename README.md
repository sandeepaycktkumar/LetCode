## LetCode Website

##URL-https://letcode.in/

##INTRODUCTION

LetCode(https://letcode.in/)  is a practice website exclusively designed for Software Testers to learn and enhance their technical skills. It provides a single platform where users can perform and practice different types of software testing activities.This test plan defines the objectives, scope, testing approach, tools, deliverables, and other necessary activities required to test the LetCode application. The purpose of this test plan is to ensure that the application behaves as expected, meets the specified requirements, and provides a reliable user experience.

##SCOPE
The following features of the website to be tested
Home Page,
Work Space,
Products,
Grooming,
Courses,
Contact.

##TESTING TOOLS

The following are the list of Tools we will be using in this Project: 

Microsoft word and Excel for Test case preparation
Selenium for automation
Eclipse IDE


##DELIVERABLES

Test plan document
Test case document 
Bug report
Test summary report
Test Signoff report
